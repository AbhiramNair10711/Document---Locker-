# Conversion Support Matrix

DocLocker provides a dedicated PDF Converter workspace inspired by iLovePDF:

| Tool Name | Source Format | Target Format | Mode / Implementation |
| :--- | :--- | :--- | :--- |
| **Merge PDF** | PDF, PDF | Combined PDF | Staging & SQLite history recording |
| **Split PDF** | PDF | Page PDFs | Staging & SQLite history recording |
| **Compress PDF** | PDF, Office | Optimized PDF | Staging & SQLite history recording |
| **PDF to Word** | PDF | DOCX | Local structure extraction / simulation |
| **Word to PDF** | DOC, DOCX | PDF | Local conversion handling |
| **PDF to PPT** | PDF | PPTX | Local conversion handling |
| **PDF to Excel** | PDF | XLSX, CSV | Local extraction handling |
| **Edit PDF** | PDF | Annotated PDF | Annotation metadata storage |
