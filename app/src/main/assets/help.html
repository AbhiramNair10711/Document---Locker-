DocLocker Help & Privacy

Your secure, local workspace for document management, expiry tracking, and preparation checklists.

1. My Vault & Document Importing

My Vault is your secure storage space for PDFs, certificates, and ID cards.

  • Import from Drive / Browse File: Tap Import / Add Document inside My Vault to select any document using the Android file picker or connected Google Drive provider.
  • Sample Document: You can instantly add a built-in sample document for testing and previewing.
  • Storage: Imported files are securely copied into app-private internal storage, ensuring they remain private and accessible.

2. Document Expiry Tracker

Keep track of important document renewals (such as passports, driving licences, and insurance policies).

  • View all tracked documents and their expiry dates in one place.
  • Tap any document card to update its expiry date using an interactive calendar date picker. Changes update in real time.

3. Readiness Radar

Prepare for common applications and travel procedures with preloaded checklists.

  • Choose from 18 predefined templates (including Visa Application, Driving Licence Renewal, College Admission, Job Application, and more).
  • Track completion progress in real time with interactive requirement checkboxes and dynamic progress percentage indicators.

4. Security & Authentication

Protect your sensitive documents with vault password protection.

  • Set up and secure your vault with a custom password upon first launch.
  • Update your vault password anytime from Settings via the Change Vault Password screen.

5. Privacy Assurance

DocLocker is designed with a privacy-first, local-only architecture:

  • Local Storage: All document metadata is stored locally in an on-device SQLite database, and files reside in app-private internal storage.
  • No Cloud Telemetry: DocLocker does not upload your documents, metadata, passwords, or personal data to any external servers or third-party tracking services.
  • Data Removal: Uninstalling the application or clearing app data securely removes all stored local vault files and database records.
